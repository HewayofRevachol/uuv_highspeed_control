# 周会摘要：GS-12 预测器 × 权重联合实验

- **历史结果（旧锁定任务）**：C4 预测器 + W1 相比 C4 + W0 的任务等权平均 `J_track` 曾低 13.46%。这不是本轮结果。
- **本轮开发集**：16/16 完整配对；D=C5/P1+W1 的平均 J 比 B=C4/P0+W1 低 76.15%，3/4 任务不劣，无 QP 失败、越界或饱和；按预注册规则冻结 D。
- **本轮新锁定集**：12/12 完整配对；D 平均 J 比 B 低 75.82%，但深度低频任务 `locked_depth_b1` 退化（D `2.1751e-9`，B `2.5498e-10`），故仅 2/3 任务不劣，严格门槛未通过。其他两个任务改善约 74.74% 与 78.87%。
- **质量**：早停、QP 失败、越界、命令/执行器饱和均 0；三任务均未触发预定义命令尖峰审查标志。
- **判断**：这组 east 高频和混合任务中 P1 显示明显收益，但存在低频深度任务退化。由于锁定集已打开，不在这些任务上重复选参；下一步如要研究调度/预测器折中，应使用全新的锁定任务。
