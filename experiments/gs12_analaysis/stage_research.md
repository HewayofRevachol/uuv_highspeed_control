# 高速 UUV 模型失配下的鲁棒 MPC 与学习型自适应控制：研究背景及文献调研需求

## 一、研究背景与核心问题

本研究面向高速无人水下航行器（Unmanned Underwater Vehicle, UUV）在复杂三维机动过程中的轨迹跟踪与约束控制，重点关注模型预测控制（Model Predictive Control, MPC）在真实动力学与预测模型存在失配时的闭环性能。

研究涉及 12、15、18 m/s 等高速工况，以及直线、水平转弯、深度变化和水平—垂直耦合机动。

在这些工况下，UUV 具有多通道耦合明显、控制执行器动态不可忽略、姿态与深度约束较紧、推进能力有限等特点。

传统 MPC 通常依赖标称动力学模型进行有限时域预测与在线优化。然而，真实 UUV 与标称预测模型之间可能存在多种差异，包括：

- 水动力参数失配：质量、阻尼、推力增益等参数偏差。
- 操纵面控制效能失配：水平和垂直控制舵的实际控制效能与预测值不一致。
- 执行器响应速度失配：真实时间常数与模型设定不一致。
- 执行器动态阶次失配：真实执行器表现为二阶动态，而 MPC 采用一阶模型。
- 控制指令传输及执行延迟失配。
- 高速下推进器接近或达到物理推力上限。

研究最初的目标是分析各种模型失配如何影响 MPC 的闭环稳定性、轨迹跟踪精度及约束满足情况，并寻找有效的鲁棒控制改进方法。

在此基础上，研究进一步尝试通过强化学习（Reinforcement Learning, RL）动态调整参考速度、预测模型修正程度或模型信任系数，希望实现固定 MPC 参数难以实现的状态自适应控制。

但目前的实验表明，确定性的保守预测模型和结构化分通道 MPC 已取得显著收益，而多轮 RL 尚未证明相对于强确定性基线存在稳定的独立优势。

因此，当前研究重点正在从“如何训练更强的 RL 策略”转向“模型失配下的最优预测偏置是否具有状态依赖性，以及是否真的需要学习型控制方法”。

## 二、已有研究发现一：特定模型失配会显著恶化高速耦合机动

### 2.1 系统性模型失配实验

研究开展了 192 条配对闭环实验：

3 种航速（12、15、18 m/s）× 4 类机动（直线、水平、深度、耦合）× 16 种真实被控对象配置。

主要结果如下：

| 模型失配类型 | 触发诊断边界的工况数 |
|---|---:|
| 质量、阻尼、推力增益各 ±10% | 各 0/12 |
| 双舵控制效能降低 10% | 2/12 |
| 全通道执行器时间常数增加一倍 | 3/12 |
| 全通道二阶执行器动态 | 3/12 |
| 仅双舵二阶执行器动态 | 2/12 |
| 双舵效能降低 10% + 全通道二阶动态 | 6/12 |
| 测试范围内的执行延迟变化 | 0/12 |

需要强调，0/12 仅意味着没有触发此次定义的诊断边界，并不代表不存在跟踪误差、推进容量问题或其他性能损失。

实验发现：

**舵效下降、执行器响应变慢以及动态阶次失配，对高速 UUV 的耦合与升沉机动具有明显影响；其中舵效下降与二阶执行器动态叠加时，可能产生更严重的闭环性能退化。**

最危险组合失配在部分工况下约 2.8 s 即触发诊断边界。

在另一项早期强耦合机动实验中，舵效下降与二阶响应叠加导致约 5.1 s 时触发俯仰边界，深度误差方差达到匹配设计闭环的约 16.25 倍。

这说明模型失配的危险性不能仅由单个参数误差百分比判断，还与执行器动态、运动通道耦合、航速和机动方式有关。

### 2.2 局部频域与奇异值分析

研究进一步采用局部频域分析及奇异值分解（SVD），评估不同失配条件下闭环误差的敏感方向与放大能力。

结果表明：

- 15 m/s 时，舵效下降和组合失配主要放大深度相关方向。
- 执行器响应变慢和全二阶动态主要影响速度相关方向。
- 18 m/s 组合失配下，多个奇异值接近，不存在稳定的唯一最敏感方向。

因此，模型失配对各运动通道的影响并不均匀。

这为采用分通道预测模型、通道相关鲁棒裕度或结构化不确定性处理提供了动机。

### 2.3 高速推进能力约束

18 m/s 直航配平时，所需推力约达到最大推力的 94.99%。

当阻尼增加 10% 或推力增益下降 10% 时，推力需求分别达到最大推力的约 104.49% 和 105.54%。

这意味着部分高速实验存在真实的物理可行性问题，而不只是 MPC 预测精度不足。

后续控制设计需要区分：

1. 模型失配引起的预测错误和闭环性能下降；
2. 执行器动态造成的控制滞后；
3. 推进器容量不足造成的任务不可行。

这三类问题不应使用同一种控制机制笼统处理。

## 三、已有研究发现二：保守预测模型能够显著改善部分困难任务

### 3.1 固定保守预测参数

研究发现，直接追求预测模型参数与真实对象一致，并不总能获得最佳闭环控制效果。

通过失配敏感性分析，构造了一个固定保守预测模型：

- 舵效预测系数取标称模型的约 0.85。
- 执行器预测时间常数取标称模型的约 2.0 倍。

这些参数并非真实系统辨识得到的准确值，而是人为引入的控制整形偏置。

其目的不是单纯提高预测精度，而是改变 MPC 对未来控制效能及响应速度的预期，从而改变控制动作的幅值、提前程度和约束处理方式。

早期配对实验中，在相同真实对象与相同前 5.1 s 评价区间内，保守模型使深度 RMSE 下降约 48.4%，但东向 RMSE 增加约 6.9%。

这表明保守模型能够改善特定通道的控制表现，但存在明显的通道间权衡。

### 3.2 留出路径验证

在四条新的耦合留出路径上，每条路径采用五个真实对象/扰动种子，对比原始 condensed N35 MPC 与保守 .85/2.0 MPC：

| 耦合路径 | 原始 N35 完成数 | 保守模型完成数 |
|---|---:|---:|
| coupled_e | 0/5 | 4/5 |
| coupled_f | 0/5 | 4/5 |
| coupled_g | 0/5 | 2/5 |
| coupled_h | 0/5 | 4/5 |
| 总计 | 0/20 | 14/20 |

在这些配对样本中，保守预测模型获得了 14 个完成情况改善、0 个恶化。

非耦合回归测试中，两者均为 10/10。

这一结果是现阶段最明确的正向实验成果之一：

**针对失配敏感性设计的固定保守预测偏置，能够显著改善部分高速耦合机动的物理完成表现。**

但也存在三个限制：

- 不同路径的收益差异较大，尚未实现全部困难任务完成。
- 较保守的模型可能改善深度方向，却恶化其他方向的跟踪。
- 模型参数越保守并不意味着控制性能越好。

尤其值得研究的是：

为什么一个在参数辨识意义上未必更准确的预测模型，反而可能比真实参数 oracle 产生更好的闭环表现？

这里可能涉及有限预测时域、约束激活、控制动作提前量、模型结构误差以及预测精度与闭环控制目标之间的不一致。

需要寻找与以下思想相关的文献：

- 面向控制性能而非预测误差的模型设计；
- 鲁棒 MPC 中的保守预测与不确定性裕度；
- Model mismatch compensation；
- Task-oriented / control-oriented system identification；
- Learning models for control rather than pure prediction；
- MPC model shaping / model tuning。

需要明确区分：本实验中的保守预测偏置是经验验证有效的控制设计，并未因此自动获得形式化的鲁棒稳定性或约束满足保证。

## 四、已有研究发现三：分通道混合预测模型比全面增加模型阶次更合理

在后续结构修改实验中，研究比较了四类 MPC：

1. 原始 22 状态、一阶执行器预测模型。
2. 保守 22 状态、一阶执行器预测模型。
3. 全通道二阶执行器预测模型（25 状态）。
4. 二阶推进 + 保守一阶双舵的分通道混合模型。

在 18 条相同的大幅机动压力测试中：

| MPC 模型 | 完成数 |
|---|---:|
| 原始 22 状态一阶 | 7/18 |
| 保守 22 状态一阶 | 18/18 |
| 全二阶 25 状态 | 14/18 |
| 分通道混合模型 | 18/18 |

全二阶模型改善了部分速度相关敏感方向，但造成深度相关性能退化。

分通道混合模型则保留了推进通道二阶结构的部分收益，同时维持保守模型较好的姿态和深度边界表现。

在 15 m/s 组合失配条件下、最高已测试频点的最大奇异增益分别为：

- 原始一阶：0.12199
- 保守一阶：0.10449
- 全二阶：0.16353
- 分通道混合：0.10446

然而，混合模型在前六个低中频测试点的最大误差增益仍可能达到原始模型的约 1.86–3.12 倍，尚未证明全频带鲁棒优势。

因此目前的结论是：

**分通道、非均匀的预测动力学建模具有明确的实验动机。不同执行器通道不一定应采用相同的模型阶次、参数保守程度或不确定性处理方式。**

值得调查：

- Actuator-aware MPC；
- Heterogeneous actuator dynamics；
- Mixed-order prediction models；
- Structured uncertainty in MIMO robust control；
- Channel-wise / axis-dependent robust MPC；
- Frequency-domain robustness shaping；
- Structured singular value / μ-analysis；
- 航行器多通道耦合控制与执行器动态补偿。

核心目标不是单纯增加预测模型的复杂度，而是找到与物理失配结构相匹配的控制设计。

## 五、强化学习探索：多轮实验尚未产生稳定的独立收益

在确定性 MPC 取得初步改进后，研究尝试利用 RL 自适应调整参考速度、模型修正强度或通道保守程度。

主要经历四轮。

### 5.1 第一轮：离散参考速度 RL

RL 在有限速度候选集合中选择参考速度，再由 MPC 完成跟踪。

记录结果为 0/6 strict_mainline，但该指标受到实验协议影响：

- deadline 被离线运行器固定标记为失败；
- 困难回合约 86% 的周期由固定 backup 接管；
- 不同估计器与控制保持周期未完全隔离。

因此，不能将这一轮解释为 RL 算法本身已经被严格证明失败。

它主要暴露了 RL 的实际动作权限不足、backup 干预过多及评价协议不一致的问题。

### 5.2 第二轮：双门控 CAT-MPC PPO

RL 输出两个连续信任系数：

\[
a_t=(\alpha_\theta,\alpha_d)
\]

分别调节历史响应参数修正和残差预测修正的使用程度。

固定保守模型 (0,0) 是架构内部的基线，并非原始名义 MPC。

在六个开发场景中：

- 固定保守门控：5/6 物理完成。
- 固定中间门控 (.5,.5)：6/6 物理完成。
- PPO 多个训练 checkpoint：均为 5/6 物理完成。

PPO 未显示相对于固定保守门控的物理完成增益，也没有超过固定中间门控。

### 5.3 第三轮：四通道 Gate PPO

动作扩展为：

\[
a_t=
[a_\theta,a_u,a_{\mathrm{vertical}},a_{\mathrm{lateral}}]
\]

意图让 RL 根据不同运动通道和状态，分别调整模型修正强度。

在 24 个开发场景中，PPO 取得 0 个失败，但固定最优门控和规则选择器也均为 0 个失败。

剔除两个接近持续推力饱和的 18 m/s 容量受限场景后，在剩余 22 个场景中：

- PPO 成本：0.67012
- fixed_best 成本：0.66432

PPO 成本高约 0.87%，RMSE 也高约 0.44%。

更关键的是，训练后的 PPO 门控均值约为：

\[
[0.502,0.499,0.455,0.500]
\]

标准差仅约 0.01–0.02。

这说明在该实验中，PPO 基本输出固定中间门控，没有形成明显的状态相关自适应行为。

### 5.4 第四轮：教师中心的安全残差 PPO

进一步采用教师中心残差策略：

\[
a_t=a_{\mathrm{teacher}}(s_t)+\Delta a_{\mathrm{RL}}(s_t)
\]

通过边界约束、QP 检查、动作变化率限制、安全投影等机制约束 RL 动作。

在 22 个非容量受限开发场景中：

| 方法 | 成本 |
|---|---:|
| rule_best | 7.09235 |
| fixed_best | 7.77689 |
| SR-PPO r0 | 7.77320 |
| SR-PPO r1 | 7.77321 |

SR-PPO 相对 fixed_best 仅获得约 0.047% 的表面成本改善，却相对 rule_best 退化约 9.6%。

同时：

- 训练 shield 投影标记比例约 95.5%–95.7%；
- 教师搜索网格只有七个有效场景；
- 部分教师目标超出残差动作的可达范围；
- 共同成功轨迹上的成本仍存在退化。

注意，投影标记比例很高，并不直接代表相同幅度的动作被拒绝；仍需测量投影距离及其对最终 MPC 指令的影响。

这一轮没有证明残差 RL 能够稳定改善强规则基线。

不同 RL 实验采用了不同场景集合、代价定义和代码版本，其绝对成本不能直接横向比较。

## 六、RL 实验共同暴露的根本问题

四轮实验目前指向以下三个研究问题。

### 问题 A：RL 是否具有实际有效的控制权限？

在部分实验中，RL 的原始动作受到 backup 或安全 shield 的强烈影响。

在其他实验中，PPO 虽然输出连续动作，但其门控几乎固定。

因此需要区别：

1. RL 网络提出的动作；
2. 经安全层处理后实际采用的门控；
3. 门控对 MPC 预测结果造成的改变；
4. 最终实际执行的推进与舵面指令；
5. 这些指令对真实闭环轨迹的影响。

如果不同 RL 动作最终产生几乎相同的实际控制指令，那么 RL 的有效决策空间可能非常有限。

### 问题 B：是否存在固定门控无法覆盖的状态相关收益？

目前多个固定门控和规则策略表现不弱于 RL。

因此，不能预先假设最优门控一定是复杂的状态函数。

需要首先回答：

\[
a^\ast(s)\stackrel{?}{\approx}a_0
\]

还是：

\[
a^\ast(s)=\pi^\ast(s)
\]

即最优模型保守程度是否真正随速度、机动、预测失配或约束裕度产生显著变化。

如果不同状态下的最优门控近似相同，固定模型整形可能已经足够。

如果存在稳定的状态依赖关系，也应先判断简单增益调度、规则或确定性优化能否表达这种关系。

### 问题 C：RL 的独立增益如何进行严格归因？

已有 RL-MPC 架构往往同时包含：

- 保守预测模型；
- 在线参数估计；
- 残差预测；
- 固定或规则门控；
- 安全投影；
- 强化学习策略。

因此，一个 RL-MPC 系统整体优于原始 MPC，不能直接证明收益来自 RL。

必须在相同预测器、估计器、MPC 和安全机制下，对比 RL 策略与固定/规则门控。

还需统一求解器、实际执行指令、状态初始化、成本函数和失败统计，避免将基础架构改善归因于学习算法。

## 七、当前拟开展的关键实验

下一阶段准备先开展“状态快照—门控扫描”实验，而不是直接增加 PPO 训练规模。

基本思路：

1. 从代表性的 UUV 闭环轨迹中采样控制状态快照，包括入弯、深度变化、姿态快速响应、执行器接近饱和和明显模型失配等状态。
2. 保存完整的控制器与真实执行器状态、历史信息和扰动条件。
3. 在相同初始条件下，对多个候选 gate 进行配对闭环 rollout。
4. 比较固定时间窗口内的轨迹成本、物理完成情况、约束裕度和实际控制指令。
5. 估计不同状态下的最优 gate 以及其相对固定 gate 的潜在收益。
6. 判断这种状态相关收益是否具有可重复性、足够的实际幅度和在线可观测性。

定义一个有限时域性能函数：

\[
J_H(s,a)
\]

其中 \(s\) 为状态快照，\(a\) 为候选门控。

进一步定义：

\[
a^\ast(s)=\arg\min_{a\in\mathcal A}J_H(s,a)
\]

并计算固定门控的潜在遗憾：

\[
\Delta J(s)=J_H(s,a_{\mathrm{fixed}})
-\min_{a\in\mathcal A}J_H(s,a)
\]

需要注意，快照级最优门控是一种离线 oracle 分析，不能直接等同于可部署的动态策略；还需考虑连续时刻之间的切换、实时可观测性和长期约束。

如果扫描显示状态依赖收益非常有限，应优先采用固定或规则门控。

如果扫描显示明显的动态收益，则进一步比较：

- 手工规则；
- 增益调度；
- 有监督学习的门控选择器；
- 上下文 bandit；
- 在线有限候选优化；
- 受约束低频 RL。

RL 只有在超越更简单方法时才具有独立研究价值。

## 八、希望文献调研 Agent 重点回答的问题

以下问题按优先级排列。

### 方向一：模型失配下的鲁棒 MPC 与保守预测整形（最高优先级）

希望找到能够解释或改进以下现象的理论和方法：

**预测模型参数不一定越接近真实参数，闭环 MPC 性能就越好。**

重点调查：

- Robust MPC 与 model mismatch compensation；
- Tube MPC、constraint tightening；
- Min-max MPC、scenario MPC、multi-model MPC；
- Control-oriented system identification；
- Task-oriented predictive model learning；
- 面向闭环代价优化的 MPC 模型参数选择；
- 面向特定执行器失配的保守预测或鲁棒性设计；
- 预测模型偏置与有限时域约束性能之间的关系。

希望回答：

1. 有没有理论或实验表明，有偏预测模型可能优于更准确的物理模型？
2. 有没有系统地选择保守参数的方法，而不是人工试探 0.85/2.0？
3. 是否可以根据不确定性范围自动优化通道相关保守程度？
4. 哪些方法能提供稳定性、约束满足或递归可行性的保证？
5. 相关方法在强耦合、多输入多输出、执行器受限系统中是否适用？

### 方向二：执行器阶次失配与分通道鲁棒控制（最高优先级）

重点调查：

- Actuator dynamics compensation；
- Actuator-aware model predictive control；
- Higher-order actuator modeling；
- Mixed-order or heterogeneous actuator models；
- Structured uncertainty and robust MIMO control；
- Channel-wise robustness shaping；
- Frequency-domain robust control；
- Structured singular value analysis；
- Underwater vehicle robust control with actuator uncertainty。

希望回答：

1. 是否有研究专门处理真实执行器为二阶、预测模型为一阶的失配？
2. 是否存在不同控制通道采用不同模型精度和不确定性描述的方法？
3. 如何解释某个通道动态建模变准确后，其他通道闭环鲁棒性反而下降？
4. 能否利用灵敏度函数、奇异值或结构化不确定性来指导 MPC 模型整形？
5. 是否可以将低频跟踪与高频鲁棒性纳入统一设计指标？

### 方向三：先验证自适应价值，再决定是否采用 RL（最高优先级）

希望寻找不依赖大规模 RL 的方法，判断自适应模型选择是否值得做。

- Context-dependent model selection；

希望回答：

1. 如何量化动态控制策略相对于最优固定策略的潜在收益上限？
2. 如何区分状态相关的真实收益和由实验噪声造成的门控变化？
3. 如何在控制任务中构造公平的固定策略、规则策略和自适应策略比较？
4. 如何用有限数量的闭环 rollout 估计各状态下的优选模型？
5. 如果 gate 只有低维连续动作，是否有比 PPO 更有效的确定性或监督式优化方法？

### 方向四：安全残差 RL、动作投影与有效学习权限（次高优先级）

2. 是否存在直接学习安全可行动作的方法，而不是先输出动作再大量裁剪？
3. 残差 RL 应该围绕怎样的教师策略构建？
4. 当强固定或规则教师已接近最佳表现，RL 是否仍有可证明或可测量的提升空间？

## 九、文献筛选与比较要求

本次文献调研不应仅以题目中是否包含 UUV、MPC 或 RL 作为依据。

优先寻找能够解决本研究具体瓶颈的论文，即使应用场景来自：

- AUV/UUV 或其他海洋航行器；
- 航空飞行器及飞行控制；
- 机器人多输入多输出系统；
- 自动驾驶及车辆横纵向耦合控制；
- 工业过程控制；
- 执行器受限、模型失配明显的非线性控制系统。

建议以近十年研究为主体，并补充真正重要的经典理论工作。需要优先考虑公开发表、具有可复现方法及充分对比实验的论文，同时关注近年预印本和开源实现。

对每篇相关论文，希望记录：

1. **文献来源**：标题、作者、年份、期刊/会议、DOI、原文链接与代码链接（若有）。
2. **解决的问题**：具体针对哪种失配、不确定性或控制约束。
3. **核心方法**：模型结构、优化目标、在线/离线计算方式、是否使用学习算法。
4. **理论性质**：是否有稳定性、鲁棒性或递归可行性保证；保证成立的假设是什么。
5. **实验对比**：是否与强 MPC、固定参数、规则控制器比较；是否提供真实闭环或硬件实验。
6. **与本研究的对应关系**：能解释哪个现有结果，或者解决哪个已知失败原因。
7. **迁移成本**：需要修改预测模型、求解器、安全机制还是训练框架；是否满足在线实时性。
8. **局限和风险**：依赖准确辨识、复杂在线优化、大量训练数据或难以满足的假设等。
9. **建议的最小验证实验**：可以如何使用现有 UUV 仿真平台，以最小改动判断方法是否有效。

特别要求区分：

- 论文已经严格证明的结论；
- 论文通过实验观察到的现象；
- 可以合理迁移到本研究但尚未验证的假设。

不得将论文中的实验优势直接表述为对本研究平台的保证。

## 十、希望 Agent 最终交付什么

希望得到的不是一个简单的“相关论文列表”，而是一份针对现有实验瓶颈的研究决策报告。

建议输出以下内容：

**第一部分：最相关的核心文献。**

优先选择 10–15 篇与现有问题直接相关的论文，说明各自的方法、可靠性和可迁移性；并补充其他值得延伸阅读的研究。

**第二部分：已有理论能否解释保守预测模型优于准确模型。**

尤其关注预测精度与闭环性能不一致、有限预测时域与约束激活，以及通道间鲁棒性权衡。

**第三部分：能否找到优于人工固定偏置的确定性方法。**

例如结构化鲁棒 MPC、模型集合选择、增益调度、面向闭环性能的参数优化等。

**第四部分：当前 RL 是否存在方法论上的缺陷。**

分析是否应该继续采用 PPO，或者先考虑监督式 gate、规则选择器、上下文 bandit、在线模型选择或其他低复杂度方法。

**第五部分：推荐三个最值得开展的后续实验。**

每个实验需给出：

- 对应科学假设；
- 参考文献；
- 核心技术方法；
- 对现有 MPC/RL 框架的改动；
- 所需对照组；
- 判断方法有效或无效的实验标准。

最终目标是从文献中找到**能够解释已有实验结果、克服明确技术障碍、并能在现有高速 UUV 平台上验证的研究方法**，而不是为了引入强化学习而继续增加网络结构或训练量。

## 十一、研究目前的核心定位

现阶段已建立的证据链是：

**模型失配诊断 → 发现执行器效能与动态失配的主导风险 → 保守预测整形显著改善部分留出任务 → 分通道混合建模显示潜力 → 多轮 RL 未超过强确定性基线 → 需要先证明状态依赖模型选择的必要性。**

研究下一阶段的首要问题可以总结为：

> 对于存在结构化模型失配、执行器动态不确定性以及严格约束的高速 UUV，如何设计能够兼顾闭环鲁棒性、跟踪精度与实时计算能力的 MPC 预测模型？在已有强保守预测和规则控制策略的基础上，是否存在具有实质收益且可在线实现的状态依赖模型调整机制？

如果现有文献能够提供具有理论依据或可系统优化的确定性方法，应优先验证这些方法。

只有在实验明确表明静态或简单规则控制器无法充分利用状态相关信息时，才进一步评估采用安全 RL 学习动态模型选择策略的必要性。
