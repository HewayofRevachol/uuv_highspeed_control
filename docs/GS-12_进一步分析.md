# GS-12：逐项失配、局部频率响应和敏感方向的进一步分析

2026-11-05；控制仓库 `926b7ac4b8559c9b2261d72e689649f6080a34b3`。本报告继续采用 Badwe 等，*Quantifying the impact of model-plant mismatch on controller performance*，JPC 20 (2010) 408–425，DOI 10.1016/j.jprocont.2009.12.006 的反事实比较与方向性思想。本轮已实际运行配对闭环、非线性闭环频率辨识、SVD 方向重放和控制器原型对照。

**主要结论是：风险并不由一个“失配百分比”决定，也不随航速单调变化。执行器响应结构、慢响应和舵效下降的叠加最容易在升沉/耦合机动触发边界；推进增益和阻尼失配在18 m/s暴露另一类能力不足。局部小信号最敏感方向可以从深度转为速度，不能用一个全局固定方向代替。预测器结构修正能明显改善速度通道，却可能恶化深度通道，必须同时评价完整频带与大幅机动。**

## 1. 本轮实验边界与可复现性

当前锁定的仓库版本 `926b7ac` 已经修复上轮指出的 residual tau 重复缩放，标签改为 v3；本轮没有继续把它当作当前缺陷。旧 `diagnose.run` 的 reset/target 注册顺序仍需留意，因此本轮直接组装声明清楚的研究植物，调用真实仓库的 `CondensedActuatorMPC`，不依赖旧诊断入口来注入参数。

研究植物使用同一水动力方程、RK4 5×.02 s；控制周期 .1 s，N35，原命令盒约束、原代价和一次 RTI 求解。除明确的控制器原型对照外，控制器参数固定。没有海流、随机噪声、RL、FSP、低层补偿或进度反馈。输入为共同的外生时间参考，位置、速度和切线姿态保持解析一致。曲线参考的北向速度固定，不等于全程切向速度固定，故这些实验不是原 H15 路径验收。

所有失配相对于固定 `MISMATCHED_PLANT`；设计基线是相对当前预测器匹配，而不是所有物理系数都取1。初始艇体状态、基线直航配平推力、执行器、队列和 MPC 计划在配对中相同；质量/阻尼/推力改变后没有重新配平，所以实验包含共同初态下的参数阶跃效应。

植物实现经过90步独立 Torch 对照，覆盖异质参数/延迟/时间常数和三种执行器结构，最大绝对差 `1.11×10⁻¹⁶`；12条匹配闭环与 MPC 自身一步传播最大差 `3.55×10⁻¹⁵`。逐项实验在每 .02 s 子步检查横向8 m、深度5 m、切向速度误差2 m/s、绝对俯仰40°；首次越界即停止并保留该子步。它们是诊断阈值，不是经过认证的安全包线。

RMSE、偏差、VR采用相同时间前缀。VR是中心化有限记录方差比，分母近零时为空；不把较早停止的短轨迹与完整24 s平均误差直接排名。还单独记录命令饱和、实际执行器子步饱和、沿程位置落后和 QP 状态。

两条区别有直接机制意义：

### 未越界也可能明显失去跟踪能力

18 m/s匀速基线配平已经需要最大推力的94.99%。阻尼+10%、推力增益−10%分别需要 **104.49%/105.54%**，超过可用推力。

在含速度变化的直线案例中，这两组推力命令全程饱和，实际推力95.25%的子步处于上限；24 s沿程分别落后 **9.10/11.04 m**，北向位置RMSE为 **6.218/7.269 m**，匹配基线仅 .223 m。现有四个诊断界没有纵向位置界，而且速度误差未超过2 m/s，所以它们显示“未越界”。应解释为推进能力不足导致的持续跟踪损失，而非通过了稳定性或任务验收。

18 m/s耦合匹配基线的推力命令饱和率也达到99.2%；其全部失配案例未越界，并不能说明18 m/s比12 m/s更稳。相同空间曲率下的向心需求和舵力都随速度平方变化，剩余推力、舵余量、响应相位和机动方向共同决定结果。

## 3. 局部频域：实际辨识了什么

在12/15/18 m/s直航配平工作点附近，以三个独立参考自由度激励：东向位置、深度、北向速度。速度参考同时积分为北向位置；东向/深度参考的导数进入速度参考，姿态由切线得到。

定义工程归一化：

```text
z = [Eref / 8m, (Dref−20m) / 5m, (VNref−U0) / (2m/s)]
e = [(Eref−E) / 8m, (Dref−D) / 5m, (VNref−VN) / (2m/s)]
e(jω) ≈ T(jω) z(jω),  T为3×3复矩阵
```

这三个独立参考生成器与三个误差量同维，避免把相关的8维位置/姿态/速度参考冒充8个独立输入。归一化决定SVD方向的工程含义；更换尺度会改变奇异值，不能忽略它。

每个输入轴独立使用多正弦，16 s起始过渡后取两个64 s整周期窗口，总时长144 s（所选频线的实际共同基周期为32 s）。每条频线归一化幅值 .006，另对部分配置做 .003 半幅检查。输入频线为：

`ω = [.19635,.39270,.58905,.78540,1.17810,1.57080,2.35619] rad/s`。

先扣除同配置零激励基线，之后从第二个窗口80–144 s提取复 Fourier 系数：`T[:,j]=E_j/R_j`。16–80 s的第一窗口用于收敛对照；同时保存非激励输出RMS占比、饱和、QP状态及原始记录。频率采用实际秒数和 `.1 s`采样，未混淆rad/sample与rad/s。

这一组完成 **82条144 s闭环、118080个控制周期**，形成13组主幅值矩阵、10组半幅矩阵和13条零激励基线。主幅值矩阵在两个窗口间的最大相对变化为 **.0503%**，半幅矩阵相对主幅值最大变化 **7.37%**；全部记录无QP失败或命令饱和，最大推力比例 .96246，最大舵命令12.945°。半幅覆盖15 m/s六个主要配置及12/18 m/s的匹配和组合；12/18 m/s的单独二阶、15 m/s的仅舵tau×2未做半幅检查。非激励输出RMS占比最高13.458%，不能把周期重复性解释成严格线性或噪声置信区间。

这是**带未来预览的参考生成器→跟踪误差**频响；MPC同时使用状态反馈、未来参考和warm start。它不是未经验证的标准输出反馈灵敏度 `(I+GC)⁻¹`，也不是论文 `SΔ`。本轮无需强行构造IMC即可完成用户要求的FRF/SVD诊断；仅从这个三自由度参考频响无法唯一反演IMC控制器。要另构IMC，必须分离参考前馈与反馈、识别真实局部反馈接口，并验证扰动注入通道，这超出了本轮已验证的信息，不用虚构RSI/DSI代替。

## 4. SVD方向已通过真实闭环重放

对每个实测频点作 `T=UΣV*`；右奇异向量是输入参考方向，左奇异向量是误差输出方向。复向量必须保留相位：

```text
z(t) = a Re[v exp(jωt)]
```

不是把 `abs(v)` 当三个同相阶跃。所有方向使用相同 `||v||₂=1` 和相同归一化幅值，因此比较没有靠减小输入范数获得收益。

15 m/s组合在2.35619 rad/s的最大方向（把主分量设为实正）约为：

```text
v = [.00078886 + .00004400j,
     .99996605 + 0j,
     .00698296 − .00430367j]
```

这基本是深度方向。归一化幅值a=.006对应主要深度幅度约3 cm；a=.06约30 cm。随后用独立单频参考重放，最长80 s，拟合48–80 s，检查基线、保守22状态、二阶25状态三个控制器，同时重放组合最小方向和仅二阶的最大速度方向，共18条记录。

基线在组合最大方向的实测增益 **.1219856**，多正弦辨识预测 **.1219884**；完整复响应相对误差约 **.38%**。组合最小方向的复响应误差约 .059%，二阶最大方向约 .087%。这验证了关键方向的复幅相重放，而非只验证奇异值大小。10倍幅值仍未触碰本次诊断界，但组合最大方向中原22/保守22的升降舵命令饱和率分别为 .75%/.25%；不能外推为所有多频或大幅机动均无约束且线性。

## 5. 针对方向的预测器与控制器改进：正反结果都保留

### 25状态结构原型

实现了可运行的 `improved_controller.py`：在原22状态上增加三维执行器速率，用二阶响应预测，保留原QP、N35、权重和盒约束。控制器不会读取仿真器真实rate、随机tau/gain/delay；只用当前/上一周期实际执行器位置、上次已发命令和自身历史队列，按固定名义二阶模型重建速率。

若五子步离散矩阵为H，令旧rate为0推进得到 `a_zero,r_zero`，则：

```text
r_previous = (a_measured − a_zero) / H01
r_current  = r_zero + H11 r_previous
```

这是无测量噪声下的两样本因果重建，不宣称对噪声鲁棒。当前固定tau=.10/.08 s时分母非奇异；实现已对奇异重建、无效时间步和过小tau增加拒绝检查。独立传播、Jacobian有限差分、观测器以及生产22状态不受污染等测试共4项通过。私有加载原QP模块并改变私有状态维数，不修改生产仓库。

### 控制权重调节的有限开发实验

针对25状态的深度方向回归，只改变pitch权重，冻结候选30/300/1000（原100），分别重放同一组合植物、同一最敏感单频参考。增益为 **.132291/.256054/.492023**，均高于原22状态 .121986，未获得更低误差；提高pitch权重反而明显变差。没有继续无界搜索或挑选一个有利样本宣称调参成功。此结果反驳“找到最敏感方向后，直接加大对应姿态权重即可解决”的简单做法。

### 分通道原型：二阶推进 + 保守一阶双舵

根据上述方向差异，进一步实现 `hybrid_controller.py`：推进采用固定名义二阶模型和因果速率重建；双舵保留一阶预测、舵效因子 .85、tau因子2。沿用原代价、约束和N35。接口为25维，其中两维舵速率恒零，实际独立状态为23维。这个候选是在看到前述结果后提出的开发改进，不属于未见工况留出验证。

## 6. 工程决策与局限

现有证据支持把“二阶推进 + 保守一阶双舵”作为下一步验证候选：它已实测保留18组机动的边界表现，并显著降低速度方向局部误差；但尚不支持宣称它优于原控制器的全部频率或全部任务。舵通道下一步应围绕低中频深度误差做多目标优化，同时约束已测最高频误差和非线性机动边界，不能只优化一个峰值或增加单个pitch权重。

对18 m/s推进能力不足，改预测器不能创造推力余量，应先把参考速度/加速度与可用推力做可行性约束；若维持同一任务，不得把降低目标速度后的低误差冒充相同任务改善。

本轮频域工作点均为直航配平，没有辨识稳态转弯/持续升沉点；大幅耦合机动另外通过非线性闭环验证，但不能据此把直航FRF推广成全航迹LTI模型。传感噪声、海流、参数随机化、实艇水动力不确定性与端到端实时预算均未在本轮覆盖。改进原型使用可部署的信息类型，但仍需这些条件的验证才能进入实际控制主线。

“最危险”的表述限定于预先给定参数幅度、四类机动、24 s窗口及七个测量频点。未触界不等于稳定性证明，最大奇异值不等于失效概率；近重根时报告敏感子空间，避免对不稳定的单个方向过度解释。

本轮没有生产代码变更或训练模型替换，实验原型、可复现脚本和原始数据通过附件交付。原始数据保留所有成功、失败和负结果，没有只选最好的控制器记录。
