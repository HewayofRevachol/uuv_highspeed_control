# GS-12：面向模型失配的 RL 文献与候选方案

2026-11-05。依据 GS-12 已交付实验、控制仓库 `926b7ac4b8559c9b2261d72e689649f6080a34b3`，以及用户指定的 academic-research-skills-codex 3.24.0（提交 `a1556557887f345aac99bdc6027e008e91fef236`）。本轮采用 `deep-research / three-way-scan`：核查候选文献的 WHY / HOW / WHAT，再提出可证伪的研究方案。**本报告没有新增 RL 训练结果；以下设计是 AI 辅助构思、尚待实验检验。**

最值得先做的路线是：**保留二阶推进与保守一阶双舵的混合 MPC，用可部署的因果历史估计失配，再让低维 RL 策略调节模型及分通道残差的信任程度。** 研究目标是减少保守舵模型的低中频误差代价，同时保留速度方向收益与大幅机动表现。第一版固定预测器结构、推力时间常数和观测器，只开放少数信任门控；质量/阻尼等混淆、未知延迟与阶次、推力能力不足分别设置后续路线，不能承诺一个门控解决全部失配。

**建议研究问题：** 在相同观测、历史、预测器、任务和计算预算下，基于因果历史的分通道信任策略，能否比开发集最优固定门控和确定性置信门控，更好地兼顾大幅机动边界表现、低中频深度误差与二阶推进的速度收益？

这是一条候选假设，尚未证明有效，也未证明文献中无人研究过。它将 RL 的贡献限定为“选择何时、在哪个通道信任估计或补偿”，使实验能够区分学习决策与预测器本身的收益。

## 3. 七类失配要分机制处理

| 失配 | 可用的因果信息与模型 | RL 可以选择什么 | 必须比较的非 RL 路线与失效边界 |
| --- | --- | --- | --- |
| 舵效 | 已发命令、可测实际舵角、速度与 q/r 响应，必要时分别辨识升降舵/方向舵 | 舵参数估计信任、升沉/横向补偿信任 | 同历史辨识 + 自适应 MPC；弱激励下效能与质量/阻尼混淆，保守回退 |
| 质量 | 加速段输入与速度/角速度响应；有界质量/惯量模型或等效潜变量 | 对模型族或输入相关残差的信任 | 递推/窗口辨识、多模型；直航稳态不足以唯一辨识惯性参数 |
| 阻尼 | 多航速、稳态与过渡响应，状态相关阻尼项 | 工况相关修正或残差信任 | 水动力模型校准、DOB/offset-free MPC；慢常值偏置不能普遍代表非线性阻力 |
| 推力增益 | 推力命令、可用推进测量、纵向加速度及余量 | 推力效能估计的信任；后续可行速度选择 | 推力校准、同历史增益辨识、参考治理；能力不足必须改变允许的任务 |
| 延迟 | 带时间戳命令队列、测量时间戳、输入输出历史 | 已验证延迟候选模型或置信权重 | 队列增强、多模型/IMM、FSP；未知分通道小延迟须处理 .02 s 子步及观测带宽 |
| 时间常数 | 激励过渡、实际执行器测量或因果估计 | τ 估计信任与滤波强度 | 同历史 τ 辨识 + 自适应 MPC；改变推力 τ 时需同步改变观测器和导数 |
| 执行器阶次 | 瞬态形状、相位、跨频响应；结构一致的隐状态观测器 | 一/二阶候选库的选择或慢上下文 | 固定混合模型、多模型似然/IMM；不能读取仿真真实阶次标志或隐藏速率 |

尤其不能把七种误差都压成一个与未来输入无关的加速度偏置：质量、舵效、推力增益会改变控制效能；MPC 改变候选输入时，误差也会改变。隐含乘性误差的残差若被当成固定外扰，可能预测值变准而控制梯度仍错。

## 4. 四条候选路线及先后次序

### A. 首选：历史条件化的分通道信任门控

保持混合 MPC 为控制骨架。历史估计器产生等效舵参数、残差及估计质量，RL 学习何时更信任保守模型、在线估计和补偿。这样将长期闭环取舍交给 RL，而命令生成、预览和约束仍由 MPC 承担。[AD01、AD02、C2]

第一版采用四维动作：`alpha = [alpha_theta, alpha_u, alpha_vertical, alpha_lateral]`，均在 [0,1]；`alpha_theta` 共同作用于现有两项等效舵参数，三个残差门控分别作用于纵向 `u_dot`、升沉俯仰 `[w_dot,q_dot]`、横向偏航 `[v_dot,r_dot]`。只有发现共同舵参数瓶颈后，再增加升降舵/方向舵的独立参数辨识与门控。

这比当前代码的两个动作多：当前只有一个共同参数门控、一个五通道共同残差门控。四维版本、混合预测器接入及历史编码尚未实现。最小可比实验可先冻结同一个历史估计器，仅比较固定、规则与 RL 四维门控，避免同时改模型、数据和策略。

### B. 后续：历史潜变量 + 执行器多模型适应

针对未知延迟、时间常数和阶次，保留可观测命令队列，建立有限候选库，如一阶/二阶、若干通道延迟及 τ 区间；各自有一致的隐状态估计器。历史网络产生任务潜变量或模型置信度，RL 决定保守程度；与似然选择、IMM、监督识别 + MPC 比较。[AD01、AD02、AD05]

先证明历史能够区分这些候选，再讨论 RL。高频传感信息不足时，.02 s 级延迟与 τ/增益可能不可辨识，应保留不确定集合而非强制输出“真实参数”。动作队列延迟与测量延迟是不同问题，分别建模、分别测试。训练随机化可使动力学在回合中变化，但应符合声明的变化率/故障机制；任意快速突变不是现有 RMA 或 AD05 的已证能力。

### C. 后续：输入相关残差动力学 / 控制目标调参

对质量、阻尼和推力效能的复杂耦合，研究 `Delta_f(history, x, a_actual_candidate)`，在 MPC 预测内滚动，并将其状态/输入导数纳入线性化。先比较 ARX、较小递归模型及物理参数辨识；仅靠监督预测已经足够时，无需加入 RL。[AD06、C2、AUV04]

RL 可用于选择残差信任、调节经约束的代价参数，或优化长期控制目标。必须区分“监督学习动力学”“元学习适应”和“RL 策略优化”。若探索 C1 式直接控制残差，应在前两条路线证明不足后进行，残差动作须有明确通道单位、范围、变化率和独立保护层；不能以现有命令裁剪代替稳定性论证。

### D. 单独任务：推力受限时的参考治理

18 m/s 的某些工况无法维持原参考。若任务允许，RL 上层选择速度/机动强度，底层 MPC 执行，并以完成时间、沿程误差、路径质量和能耗共同计分。首先比较确定性推力余量治理器和同候选集最小风险/代价规则。现有 H15 速度策略使用 13–17 m/s 候选，不等同本次 12/15/18 m/s 契约，不能直接套用。

此路线改变参考时间计划，应单独报告。降速后误差变小不算固定外生时间参考跟踪的改善。A–C 的固定任务实验仍需如实报告能力不足，不能通过隐藏降速绕过它。

域随机化与对抗训练是上述路线的训练工具：[AD03、AD04、AUV01] 提供动机；先用已有数据校准范围，再增加交互、漂移与结构差异。不能用更宽的随机化自动替代缺失的执行器结构，也不能把有界外力对手当成七类模型失配的全集。

**信息与估计。** MPC 每 .1 s 执行，门控初设每 .5 s 更新。使用最近约 1–2 s 的测量/估计状态、实际可获得的执行器量、已发命令队列、预测创新、约束余量与共同参考预览。窗口长度是开发超参数；先冻结因果估计器，之后再比较 TCN/GRU 历史编码。观测归一化只用训练集。真实质量、阶次、延迟、仿真内部 .02 s 无噪状态、未来扰动只准进入评估日志；实际执行器若不可测，应经过独立因果观测器估计并计入误差。

**结构与动作。** 固定二阶推进、一阶双舵、名义推力 τ 及推力速率观测器。令等效舵参数 `theta=[gain,tau_scale]`，保守端点为 `.85/2.0`，先做参数混合：

`theta_k = theta_safe + alpha_theta,k * (theta_hat_k - theta_safe)`。

这不是混合两个 MPC 命令，也不是混合两个不同阶次模型。估计和参数均限制在声明范围；四个门控采用有界映射、变化率约束，初值可沿用每 .5 s 最大 .25，再按开发数据验证。整个 N35 预测窗固定当前门控，每次更新重新计算一致的传播与 Jacobian，并检查 warm start。仅两个端点表现良好不足以保证所有混合与切换良好。

**残差定义。** 固定参考离散模型 `F_ref`，门控后为 `F_theta`，二者使用相同因果估计增广状态 `z_hat` 和真正已发出的命令 `u_issued`；`P_nu` 只选取可测/估计的五维体轴速度 `[u,v,w,q,r]`。同一数据点定义 `d_ref^nu = (nu_next - P_nu F_ref(z_hat,u_issued))/dt`，再重基准为 `d_theta^nu = d_ref^nu - P_nu(F_theta-F_ref)/dt`。该等式针对离散一步误差，不使用25维植物真状态标签；将所得量作为现有接口的连续加速度残差再积分是近似，须做命令重放和单位/离散化验证。初版在已观测点构造后用声明的保持/AR(1)外推，承认其对未来候选输入的限制，后续再对照输入条件残差。不可把相对于完整 `theta_hat` 的旧标签无说明地加到部分门控模型上。三类残差全信任时，上述校正在该观测点可能抵消参数门控的局部作用，所以还要报告门控对应用预测与首命令的实际敏感度、固定参数门控消融，不能只凭 `alpha_theta` 大小解释物理信任。推力二阶及舵参数改变时，标签、状态、补偿开关与估计器版本统一冻结。

**学习器。** 先复用有界 PPO 门控接口，冻结估计器和残差预测器，只训练信任决策。RL 拟合的是闭环累计目标，不是真实物理参数；特权 critic 若以后使用须单列，actor 保持部署信息。第一版不同时开放速度选择、MPC 权重、全部模型参数和直接舵残差。否则无法判断收益来自哪一处。

**目标。** 固定外生时间参考，沿用归一化输出 `e_n=[east_error/8m, depth_error/5m, north_velocity_error/(2m/s)]`，并另计纵向位置滞后、姿态、控制消耗和变化率。建议训练目标形式：

`J = sum_k dt * (||e_n||_Q^2 + w_along*e_along^2 + ||delta_u||_R^2 + w_sat*occupancy + w_alpha*||delta_alpha/dt_alpha||^2) + J_failure`。

各项先统一无量纲尺度，再只在开发集选择权重；这不是已经调好的奖励。若快层折扣为 `gamma_fast`，慢层奖励为 `R_n=sum_{i=0}^{m-1} gamma_fast^i*r_{5n+i}`，bootstrap乘 `gamma_fast^m`；正常 `m=5`，提前截断使用实际步数，真正终止不bootstrap。只有无折扣时才直接相加五步奖励。早停、吸收态剩余期代价和终止/截断口径预先固定。评价不以 return 排名替代失败率、首次越界、共同前缀误差和完成时间，避免早停造成 RMSE 假改善。

**保护与回退。** 输入幅值/变化约束、预测约束、超时/QP 失败回退及低置信回退分别记录。当前诊断阈值与事后终止不是认证安全层；保守混合 MPC 仅是开发中表现较好的回退候选。若要声称 C3 式安全过滤，必须另建立初始可行域、终端恢复策略、模型不确定性界及实时可行性验证。本轮不作此保证。

**时间尺度。** .5 s 门控应主要估计工况与信任，不承担逐相位抵消 .375 Hz 误差的任务。最高频率每周期仅约 5.33 次门控决策，保持与估计滞后会影响相位。先比较固定、.5 s 动态门控与不同门控时钟相位；若有必要再比较 .1/.5/1 s，但按物理秒统一动作变化率、历史时长、折扣与训练预算。

当前实现位置与接入风险详见 `code_integration_notes.md`：`aav_mpc/condensed_mpc.py:216` 为参数门控，`:238` 为残差门控；`experiments/h15_cat_mpc/run_episode.py:399` 为慢门控节奏。GS-12 混合原型仍在独立研究目录，并未接入生产 CAT-MPC。未知阶次研究尤其要消除 `run_episode.py:70` 通过植物 hook 选择标签模型结构的潜在信息泄漏；DDAT 的内部子步状态标签也需改成部署可得信息。当前 v3 已修复旧 τ 重复缩放问题，不把它重复当作新缺陷。

## 6. 如何利用 SVD，而不把局部结论扩大

对归一化参考至误差映射 `T_n(jw)=U Sigma V*`，右奇异向量 `v_i` 是**参考输入方向**，左奇异向量 `u_i` 是**误差输出方向**。训练参考可用 `r_n(t)=a Re[v_i(jw) exp(j*(w*t+phi))]`，保留各通道相对复相位，并通过与原实验一致的路径/速度/姿态生成链保证参考可实现。不能简单取向量绝对值，也不能直接把右向量用于输出误差惩罚。

建议训练混合轴向、开发集敏感方向/子空间和随机复方向；频率在已测范围及允许带宽内连续变化，保留未见频点、相位、幅值与非周期机动。若增加方向性损失，使用冻结的开发集左子空间及明确的因果滤波/频带能量定义，同时始终保留完整误差范数；首版可以只用 SVD 设计参考，不增加复杂频域奖励。18 m/s 近重根采用子空间投影，避免强制追踪唯一向量。

评价必须区分三种对象：

1. **固定门控/模型：** 沿用周期、半幅、零激励与重复试验检查，得到该工作点的局部经验频响。
2. **先适应再锁定门控输出与模型：** 辨识策略所选择控制器的条件频响。只冻结网络权重不等于锁定门控。
3. **动态门控开启：** 报告指定激励统计下的经验响应或最佳线性近似，同时记录边带、谐波、未激励频率能量、幅值及门控时钟相位敏感性。多率自适应系统不能自动当作单率 LTI。

只在局部线性/时不变近似、模型分解和重构响应均经验证后，才讨论局部 IMC 表示；不从 RL 的一张奇异值图直接推出全局稳定性或 H∞ 保证。必须同时展示速度收益、深度代价、全矩阵最大奇异值及总误差能量，防止把同频误差搬到边带后误判成功。

## 7. 配对验证、消融与停止条件

**先修实验契约，再训练。** 先验证混合预测器接入、参数混合后的传播/Jacobian、观测器一致性、残差基准、已发命令、真值隔离和计时。在无 RL 下复现开发回归。旧仓库的单 seed、4000 次门控决策 pilot 没有可靠超过固定半门控，但使用旧版标签/代码；它仅是历史提醒，不能作为本方案或当前 v3 的性能结论。

**最小比较组。** 门控决策比较组共享预测器、估计器、历史、数据、补偿、预览、约束及决策频率；不同预测结构的机制参照组单列，不能把它们之间的收益归给 RL。固定门控应在开发集调优，不能只保留随意常数。

| 组 | 用途 |
| --- | --- |
| 原 22 状态、保守 22、固定混合预测器 | 保留已有机制参照，区分结构收益 |
| 同历史辨识 + 自适应 MPC；同残差 + 最优固定门控 | 排除“只是更好辨识/监督预测”的解释 |
| 创新/估计质量/约束余量驱动的确定性滞回门控 | 检验是否需要学习长期决策 |
| 相同四维动作的 PPO 门控 | 检验 RL 额外价值 |
| PPO 先适应后锁定、去历史、不同门控相位 | 检验时变决策、记忆与同步依赖 |
| 后续路线才加：IMM、多模型、DOB/FSP、输入条件残差与确定性参考治理 | 针对结构失配、扰动和能力不足，保持任务口径一致 |

预算有限时先固定同一个历史估计器，只做“开发最优固定门控—确定性门控—RL—RL 锁定”四组，胜出后才扩大结构。原有 A0–A4 两维门控可作为接口回归，但不能替代新四维动作空间的强固定对照。

**数据划分。** 已有 382 条全部标为开发/回归。新建植物参数、路径、初态、噪声、相位和随机种子清单，按回合/植物配置划分训练、开发、最终留出，禁止按同一轨迹的滑窗随机拆分。覆盖：单因素；留出的参数组合；τ/延迟/阶次交互；缓慢漂移/突变；传感器噪声和时间戳误差。训练分布内与范围外分开统计，未满足推进能力的工况单列。新随机种子仍在同一水动力方程内时只能称同模型族留出，不是实艇迁移验证。

**重复与指标。** 初步预算可从至少 5 个独立训练 seed 起步，再依方差决定是否扩展；5 个不构成统计充分性保证。所有策略在相同留出场景/扰动 seed 配对，报告每个训练 seed 的结果及跨 seed 区间，以独立训练实例/策略为簇，整簇 bootstrap 其全部场景结果；若同时重采样场景，各方法使用相同场景索引，保持场景配对并按预定工况层汇总。不要把同一策略的多个场景或时间步当独立训练重复。[C5] 指标至少包括首次触界、完成比例、共同前缀与完整成功轨迹误差（两者分列）、纵向滞后、峰值姿态、命令/实际执行器饱和、QP/超时/回退、总控制周期耗时、频响及失真。执行器与边界检查沿用一致 .02 s 子步口径。

**预先声明的晋级条件。** 第一阶段要求在固定参考下，RL 相对强固定与确定性门控呈现可重复的低中频误差改善，同时未增加诊断失败、未破坏速度方向收益或显著提高边带误差；具体效应阈值和允许差异应在开发试验后、最终测试前冻结。不仅挑选最优 seed，也不在最终测试结果上反复调奖励。约束违例减少与误差改善分别呈现，不压成一个总分掩盖取舍。

**停止条件。** 如果同历史的非 RL 方法已经达到相同或更好水平，或收益主要来自真值泄漏、参考改变、早停口径、门控时钟同步或更好的监督预测器，则不把它算作 RL 贡献。若加大网络/预算仍不能超过调好的固定与规则门控，停止扩展 RL，回到可辨识性、执行器模型、传感与可行性分析。负结果也是有效研究结论。

若实验通过，可形成的论文主线是“方向与频带约束下的失配信任分配”，证据链包括：失配机制 → 方向性代价 → 同信息强基线 → RL 门控的独立贡献 → 局部频域与非线性机动交叉检验。不能仅以“RL + MPC + UUV”的组合声称创新。
